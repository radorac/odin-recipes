# Odin Recipes

This project is part of **The Odin Project** Foundations course.

## About

The goal of this project is to build a basic recipe website using only HTML. The website consists of a main page with links to several recipe pages. Each recipe includes an image, description, ingredients, and preparation steps.

## Skills Demonstrated

By completing this project, I practiced:

- Creating a basic HTML document structure
- Working with headings, paragraphs, lists, and images
- Creating links between multiple pages
- Organizing files and folders
- Writing semantic HTML
- Using Git and GitHub for version control

## Technologies Used

- HTML5
- Git
- GitHub

## What I Learned

This project helped me become more comfortable with creating multi-page websites, organizing project files, and using Git to track changes. It also reinforced the fundamentals of HTML before moving on to CSS.
